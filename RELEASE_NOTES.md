# Hengliyuan Sample Comparison v0.1.0

Initial independent release. Record coded sweetener observations in an actual application and prepare a revision discussion.

Includes company-template review PDF, browser-only state, no login, no automatic submissions and no private company/customer database. Individual observations are not a sensory-panel study, statistically significant ranking, product endorsement or production approval.

See README for local use, static deployment and tests. Code MIT; brand identifiers separately reserved. Live demo: https://briton2008.github.io/hengliyuan-sample-comparison/
